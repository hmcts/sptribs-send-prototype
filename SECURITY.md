# Reporting a vulnerability

Please **do not** open a public issue for a security vulnerability.

Report it to HMCTS by email to <security@hmcts.net>, including:

- the repository and the affected file or endpoint
- what an attacker could do
- how to reproduce it

You will get an acknowledgement within 3 working days. Please give us a reasonable
opportunity to fix the issue before disclosing it publicly.

This repository is a prototype and is deployed only to non-production environments. It holds
no production data.
